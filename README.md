# التوأم الرقمي لمزرعة المانجو 🥭

تطبيق ويب تفاعلي (React + Vite + Tailwind) لإدارة مزرعة مانجو على شكل شبكة
(30 صف × 60 عمود)، مع وضعين: **الإدارة والبيانات** لتسجيل بيانات كل شجرة،
و**تخطيط المزرعة** لتحديد الشجر والمروى والمصرف والطريق في كل مساحة.

## ما تم إصلاحه/إكماله في هذه النسخة

1. **مشروع Vite كامل وجاهز للنشر** بدل ملف component واحد فقط: تمت إضافة
   `package.json`, `vite.config.ts`, `index.html`, `tailwind.config.js`,
   `postcss.config.js`, `vercel.json`, وملف الدخول `src/main.tsx`.
2. **سبب فشل البناء الأساسي**: الأيقونة `Road` من مكتبة `lucide-react` غير
   موجودة أصلاً في المكتبة (لا يوجد export بهذا الاسم)، وهذا كان يوقف عملية
   الـ build بالكامل على Vercel. تم استبدالها بأيقونة `Route` الصحيحة.
3. **التخزين المحلي/السحابي أصبح يعمل فعلياً**: الكود الأصلي كان يعتمد على
   متغيرات (`__firebase_config`, `__app_id`, `__initial_auth_token`) غير
   موجودة خارج بيئة معينة (AI Studio)، فكان Firebase يُهيَّأ بمفاتيح وهمية
   ويفشل تسجيل الدخول عند التشغيل الفعلي. الآن:
   - **بدون أي إعداد**: التطبيق يعمل مباشرة ويحفظ كل البيانات في
     `localStorage` بالمتصفح.
   - **لتفعيل المزامنة السحابية**: فقط أضف متغيرات البيئة `VITE_FIREBASE_*`
     (انظر `.env.example`) في إعدادات مشروع Vercel، وسيتحول التطبيق تلقائياً
     للعمل بـ Firebase Auth + Firestore بدون أي تعديل بالكود.
4. **إصلاح خطأ منطقي في عرض حالة الأشجار**: كل مساحة شجرة كانت تظهر افتراضياً
   باللون الأخضر ("سليمة") حتى لو لم يتم إدخال أي بيانات لها فعلياً، رغم وجود
   رسمة "شجرة فارغة" رمادية في الكود لم تكن تظهر أبداً. الآن المساحة تظهر
   فارغة (رمادية) حتى يحفظ المستخدم بياناتها من النافذة المنبثقة.
5. **إضافة شارة صغيرة في الهيدر** توضح هل التطبيق يعمل حالياً في وضع
   "محلي 💾" أو "سحابي ☁️ (Firebase)".
6. خط **Cairo** العربي مضاف عبر Google Fonts لعرض أفضل للنصوص العربية،
   وتمت إضافة حزمة `tailwindcss-animate` حتى تعمل حركة فتح نافذة تعديل
   الشجرة (`animate-in fade-in zoom-in`) التي كانت تستخدم بدون أن تكون
   متاحة أصلاً في Tailwind الأساسي.

## التشغيل محلياً

```bash
npm install
npm run dev
```

سيعمل التطبيق على `http://localhost:5173`.

## النشر على Vercel

**الطريقة الأسهل:** ارفع المجلد على مستودع GitHub ثم:

1. اذهب إلى [vercel.com](https://vercel.com) → New Project → اختر المستودع.
2. Vercel سيكتشف أنه مشروع Vite تلقائياً (الإعدادات موجودة بالفعل في
   `vercel.json`)، فقط اضغط Deploy.
3. (اختياري) لو عايز مزامنة سحابية بـ Firebase: من Project Settings →
   Environment Variables، أضف نفس المتغيرات الموجودة في `.env.example`
   بقيمها الحقيقية من Firebase Console، ثم أعد النشر (Redeploy).

**أو عبر Vercel CLI:**

```bash
npm i -g vercel
vercel
```

## تفعيل Firebase (اختياري)

1. أنشئ مشروع على [Firebase Console](https://console.firebase.google.com).
2. من Authentication → Sign-in method: فعّل **Anonymous**.
3. من Firestore Database: أنشئ قاعدة بيانات (Production أو Test mode).
4. من Project Settings → عام: انسخ إعدادات الويب (Web app config) وضعها في
   ملف `.env` محلياً (انسخ `.env.example` أولاً) أو في متغيرات بيئة Vercel.

## بنية المشروع

```
├── index.html
├── vercel.json          # إعدادات النشر + توجيه SPA (لمنع أخطاء 404)
├── vite.config.ts
├── tailwind.config.js
├── src/
│   ├── main.tsx          # نقطة الدخول
│   ├── App.tsx            # التطبيق كاملاً (الشبكة، النافذة، الحفظ)
│   └── index.css
└── .env.example           # متغيرات Firebase الاختيارية
```
